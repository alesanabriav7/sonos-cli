# Support

- Use [Discussions](https://github.com/alesanabriav7/sonos-cli/discussions) for
  installation, usage, automation, and LLM integration questions.
- Use a bug report for reproducible failures.
- Use a device support report to share read-only compatibility evidence.
- Use private security advisories for vulnerabilities.

This is an independent community project and is not affiliated with or
endorsed by Sonos, Inc.
